Features

Everything you need to
secure your scripts

A full-featured auth platform built specifically for the Roblox ecosystem.

🔑

Key Management

Create, revoke, and manage authentication keys. Set expiry dates, assign subscription tiers, and add notes to each key.

🛡️

HWID Locking

Bind keys to hardware IDs on first use. Prevent key sharing and ensure each key is tied to a single device automatically.

📊

Execution Tracking

See every script execution in real time. Track Roblox usernames, executors, game IDs, and timestamps for full audit logs.

⚡

KeyAuth Compatible

Drop-in replacement for KeyAuth's API. Works with existing Lua loaders with minimal changes — just swap the host.

📜

Script Serving

Host and serve your Lua scripts directly through GoatAuth. Route different scripts per game ID with subscription tier support.

🚫

Blacklist & Bans

Ban users instantly with a reason. Banned users are blocked at the API level — no script loads, no exceptions.

🏷️

Subscription Tiers

Offer free and premium tiers. Load different scripts per tier — free users get base scripts, premium users get full access.

🔒

Anti-Tamper Ready

Built-in loader supports HTTPSpy detection, anti-cheat scanning, and HWID verification before any auth request is made.

How it works

Simple integration,
powerful protection

01

Create a Key

Generate authentication keys from the admin panel. Set subscription tier, expiry date, and HWID locking settings.

02

Distribute to Users

Give keys to your users. Each key maps to a unique username. Users set Goat_key = "username" before executing.

03

Loader Authenticates

The GoatAuth loader calls our KeyAuth-compatible API, verifies the key, locks the HWID, and loads the script automatically.

04

Track Everything

Every execution is logged — Roblox username, executor, game, job ID, and hardware ID — visible in your dashboard.

Integration

One-line setup

Users just set their key and execute. That's it.

Lua 
-- User sets their GoatAuth key before executing
Goat_key = "YourKeyHere"

-- Then execute the GoatAuth loader
loadstring(game:HttpGet("https://yoursite.com/loader.lua"))()
The loader handles everything: anti-tamper checks, key validation, HWID locking, script selection, and execution tracking.
